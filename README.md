# Full Court 3D

Three.js와 Rapier 3D로 제작한 브라우저용 1대1 농구 게임입니다. 기존 macOS 네이티브 버전과 별도로 개발됩니다.

## 실행

```sh
npm install
npm run dev
```

## 조작

- 방향키 또는 WASD: 이동
- Space: 점프
- X 누르기/떼기: 타이밍 슛
- C: 수비·스틸·블록
- Z: 공을 가진 상태에서 근거리 덩크
- K 또는 Shift: 대시
- L: HEAT 스킬
- I: 선수 스타일 교체

경기는 90초이며 동점이면 골든 포인트로 이어집니다. 득점한 경우에만 센터 코트로 초기화되고, 빗나간 공은 그대로 리바운드 경쟁으로 이어집니다.
